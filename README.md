# Python Practice

I wrote these nine short Python scripts to practice working with user input, converting data types, and using loops and conditionals.

## Featured exercises

| Script | What it does |
| --- | --- |
| `T5.py` | Calculates a bill from the quantity and price per unit. |
| `T6.py` | Collects five ratings and calculates their average. |
| `T7.py` | Averages three marks and gives feedback based on the result. |
| `T9.py` | Calculates total and average revenue for three months. |

## Run an exercise

Requires Python 3. No extra packages are needed.

```bash
python T7.py
```
